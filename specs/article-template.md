# 文章模板规范（个人网站首发）

> 文章统一模板。新建文章：复制 `articles/templates/standard-template.md`，按本规范填写。静态校验：`tools/check-articles.sh`。

## 发布渠道

- **个人网站（canonical）**：仓库内的 `articles/` 是事实源。模板与规范不依赖任何具体分发渠道——可被个人网站渲染、被转载到微信公众号、也可以被任何其他渠道引用。
- **微信公众号【如春日午后阳光】（转载渠道）**：由用户自行决定是否转载、如何排版、是否使用"阅读原文"链接回个人网站 URL。AI 不参与公众号的发布与排版。

```markdown

1. [章节一](#章节一)
2. [章节二](#章节二)
3. [总结](#总结)
4. [参考资料](#参考资料)

## 章节一

[正文。代码块标注语言：]

```rust

## 措辞与文体

撰写前必读 [rules/article-voice.md](../rules/article-voice.md)。本项目文章基调为**成熟、稳重的工程复盘**；实战类推荐「背景 → 编号问题/教训 → 总结」结构。标杆范文：`articles/2c2g-server/06-ai-collab-engineering-lessons.md`。

## 元素规范

### 摘要

- 150–200 字；写清问题 + 价值点；格式固定 `> **摘要**: `（静态门禁检查）

### 代码示例

- 完整代码来自仓库时注明文件路径，方便读者对照
- 说明性片段不得冒充「已验证」；跑过的才说跑过
- 代码块必须标注语言（`rust` / `bash` / `toml` / `yaml`）

### 参考资料

- **直接展示完整 URL**（`资料名称：https://…`），不用 Markdown 超链接 —— 个人网站渲染器普遍会丢地址
- 至少包含与主题直接相关的官方文档

### 提示框

```
> **💡 提示** / **⚠️ 注意** / **❌ 警告** / **✅ 推荐** / **📝 说明**
```

## 文章类型模板要点

| 类型 | 必备章节 |
|------|----------|
| 入门教程 | 前置知识 → 核心内容 → 常见问题 → 下一步 |
| 实战复盘（本项目常用） | 背景/选型 → 实现细节 → 踩坑与解决 → 数据/效果 → 总结 |
| 进阶原理 | 背景动机 → 原理 → 代码实现 → 性能/边界 → 最佳实践 |

## 格式约定

- 标题层级不跳级（`#` → `##` → `###`）
- 中英文之间留空格；中文语境用中文标点
- 表格列数 ≤ 4，避免排版溢出
- 正文可正常用 Markdown 超链接；**仅「参考资料」章节例外**

## 版权声明模板

固定格式：

```
**版权声明**: 本文原创发布于个人网站 https://rcrwhyg.com/articles/<permalink>/，作者：如春日午后阳光。未经授权请勿转载。
```

- `<permalink>` 替换为该文章在个人网站的固定链接 slug（如 `01-the-modest-start`）
- 不要在版权声明中提及微信公众号；公众号转载由用户自行处理

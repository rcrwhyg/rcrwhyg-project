# 文章模板规范（公众号）

> 公众号文章统一模板。新建文章：复制 `articles/templates/standard-template.md`，按本规范填写。静态校验：`tools/check-articles.sh`。

## 标准模板

```markdown
# [文章标题]

> **摘要**: [150–200 字概要：这篇文章解决什么问题、读者能带走什么]

## 目录
1. [章节一](#章节一)
2. [章节二](#章节二)
3. [总结](#总结)
4. [参考资料](#参考资料)

## 章节一

[正文。代码块标注语言：]

```rust
// 完整示例尽量来自本仓库真实代码，并注明路径，如：
// 见 src/server/session.rs
fn example() {}
```

> **💡 提示**
> 重要提示信息

> **⚠️ 注意**
> 容易踩的坑

## 总结

### 核心要点
1. **要点一**: 简要说明
2. **要点二**: 简要说明

## 参考资料

1. Leptos 官方文档：https://leptos.dev
2. Axum 文档：https://docs.rs/axum
3. 其他资料名称：完整URL

**版本信息**: 本文基于 Leptos 0.8 / Axum 0.8 / Rust <版本>，写于 <YYYY-MM>。

---

**版权声明**: 本文原创发布于微信公众号【<公众号名称>】，转载请注明出处，侵权必究。
```

## 元素规范

### 摘要
- 150–200 字；写清问题 + 价值点；格式固定 `> **摘要**: `（静态门禁检查）

### 代码示例
- 完整代码来自仓库时注明文件路径，方便读者对照
- 说明性片段不得冒充「已验证」；跑过的才说跑过
- 代码块必须标注语言（`rust` / `bash` / `toml` / `yaml`）

### 参考资料
- **直接展示完整 URL**（`资料名称：https://…`），不用 Markdown 超链接 —— 公众号转换会丢地址
- 至少包含与主题直接相关的官方文档

### 提示框
```
> **💡 提示** / **⚠️ 注意** / **❌ 警告** / **✅ 推荐** / **📝 说明**
```

## 文章类型模板要点

| 类型 | 必备章节 |
|------|----------|
| 入门教程 | 前置知识 → 核心内容 → 常见问题 → 下一步 |
| 实战复盘（本项目常用） | 背景/选型 → 实现细节 → 踩坑与解决 → 数据/效果 → 总结 |
| 进阶原理 | 背景动机 → 原理 → 代码实现 → 性能/边界 → 最佳实践 |

## 格式约定

- 标题层级不跳级（`#` → `##` → `###`）
- 中英文之间留空格；中文语境用中文标点
- 表格列数 ≤ 4，避免公众号排版溢出
- 正文可正常用 Markdown 超链接；**仅「参考资料」章节例外**
